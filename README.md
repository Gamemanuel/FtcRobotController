# FTC Robot Controller – Team 10523 "The Dragons"

This repository contains the **public FTC SDK** customized for **Team 10523 – The Dragons** for the **DECODE (2025–2026)** competition season.

It is based on the official [FIRST Tech Challenge SDK](https://github.com/FIRST-Tech-Challenge/FtcRobotController) and includes our team’s code, configuration, and enhancements.

---

## Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Gamemanuel/FtcRobotController.git
```
```bash
cd FtcRobotController
```

2. Open in Android Studio
- Install Android Studio Ladybug (2024.2) or later.
- From the Welcome Screen, choose Open and select the FtcRobotController folder.
- Let Gradle sync and download dependencies.
3. Build and Deploy
- Connect your Robot Controller device via USB.
- Select the FtcRobotController run configuration.
- Click Run ▶ to install the app on the device.
